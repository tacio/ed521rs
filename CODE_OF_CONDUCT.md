# Code of Conduct

This project follows the [Contributor Covenant, version 2.1][covenant].

In short: be respectful, assume good faith, and keep discussion about the work. Harassment,
personal attacks and discriminatory language are not tolerated in issues, pull requests or any
other project space.

Report unacceptable behavior with GitHub's [Report content][report] option on the comment or
issue, or contact the maintainer privately through their [GitHub profile][maintainer]. Every
report is reviewed and kept confidential. The maintainer may remove content or block
participants who break these rules.

[covenant]: https://www.contributor-covenant.org/version/2/1/code_of_conduct/
[report]: https://docs.github.com/en/communities/maintaining-your-safety-on-github/reporting-abuse-or-spam
[maintainer]: https://github.com/tacio
